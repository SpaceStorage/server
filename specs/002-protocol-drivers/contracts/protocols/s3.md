# Protocol Contract: `s3`

**Crate**: `crates/handler-s3` | **Stack**: `axum`/`hyper` 1.x, in-house SigV4 (`hmac`, `sha2`, `hex`), `quick-xml`, `md-5` | Research: R7

| Item | Value |
|------|-------|
| Wire version | HTTP/1.1 (keep-alive), HTTP/2 over TLS; **S3 REST API** (2006-03-01) subset; path-style `/{bucket}/{key}` always; virtual-host style when `protocols.s3.virtual_host_suffix` is set and `Host` = `<bucket>.<suffix>` |
| Signature (FR-004) | HTTP request line within 1 s; otherwise `400` text/plain and close |
| Authentication | **AWS Signature Version 4** — `Authorization: AWS4-HMAC-SHA256 Credential=<access_key>/<date>/<region>/s3/aws4_request, SignedHeaders=…, Signature=…` (any region accepted; documented `us-east-1`), presigned query (`X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=…&X-Amz-Signature=…&X-Amz-Expires=`), payload hashes `<sha256>`, `UNSIGNED-PAYLOAD`, `STREAMING-AWS4-HMAC-SHA256-PAYLOAD` (chunk signatures verified), `STREAMING-UNSIGNED-PAYLOAD-TRAILER`; clock skew ≤ 15 min (`RequestTimeTooSkewed`); `access_key` → principal name, secret from `Authenticator::SigV4`; SigV2 → `400 InvalidArgument "SigV2 not supported"`; anonymous → `403 AccessDenied` |
| Namespace / schema | credential-bound (FR-009a); bucket = container in schema `public`; bucket names unique per namespace, not cluster-wide (Story 1 scenario 12) |
| Session identity | `User-Agent` → `client_app`; `x-amz-request-id` and `x-amz-id-2` on every response |
| Type option | `PUT /{bucket}` headers `x-spacestorage-type: <type>`, `x-spacestorage-opt-<name>: <value>`; default `object_collection`; `CreateBucketConfiguration` body accepted (LocationConstraint ignored) |
| Listing (FR-013) | `GET /` `ListBuckets` → `<Buckets><Bucket><Name/><CreationDate/><SpaceStorageType>…</SpaceStorageType></Bucket>…` (extension element; stock clients ignore it); `GET /?spacestorage=containers` JSON |
| Native mappings | `object_collection` ↔ objects (key, body, `Content-Type`, `x-amz-meta-*`, ETag, Last-Modified); `kv_collection` ↔ objects with key = kv key and body = value (`Content-Type: text/plain`) |
| Canonical carrier | object body with `Content-Type: application/vnd.spacestorage.canonical+json; v=1` — `PUT /{bucket}/{key}` with canonical body on any type; `GET` returns canonical body for foreign types |
| Type ops | `POST /{bucket}?spacestorage-op=<op>` with canonical `op-args` body → canonical `op-result` body (e.g. `?spacestorage-op=knn`) |
| Options | headers `X-SpaceStorage-Quorum`, `X-SpaceStorage-Timeout`, `X-SpaceStorage-Session` (may be left out of `SignedHeaders`); response headers `X-SpaceStorage-Applied-*`, `X-SpaceStorage-Options-Source` |
| Operations (v1) | `ListBuckets`, `CreateBucket`, `HeadBucket`, `DeleteBucket` (must be empty → `409 BucketNotEmpty`), `GetBucketLocation` (`us-east-1`), `GetBucketVersioning` (`Suspended`), `GetBucketAcl` (owner FULL_CONTROL), `ListObjectsV2` (`prefix delimiter max-keys continuation-token start-after encoding-type=url fetch-owner`), `ListObjects` (V1, `marker`), `PutObject` (`Content-MD5`, `x-amz-checksum-sha256/crc32/crc32c` verified, `x-amz-meta-*`, `Content-Type`, `Cache-Control`, `Content-Disposition/Encoding`, `If-None-Match: *`), `GetObject` (`Range`, `If-Match/None-Match/Modified-Since/Unmodified-Since`, `response-content-*` overrides, `partNumber`), `HeadObject`, `DeleteObject`, `DeleteObjects` (POST `?delete`, quiet mode), `CopyObject` (`x-amz-copy-source`, `x-amz-metadata-directive`), `CreateMultipartUpload`, `UploadPart` (≤ 10 000 parts, ≥ 5 MiB except last), `UploadPartCopy`, `CompleteMultipartUpload`, `AbortMultipartUpload`, `ListParts`, `ListMultipartUploads`, `GetObjectAttributes`; ETag: MD5 hex for single-part, `<md5-of-md5s>-<N>` for multipart; `x-amz-storage-class: STANDARD` |
| Not supported (v1) | versioning (enable → `501`), object lock, lifecycle, replication, website, CORS config, bucket policy/ACL writes (until `07`), SSE headers (`x-amz-server-side-encryption` → `501` until `07` encryption), `SelectObjectContent`, tagging → `501 NotImplemented` with `<Resource>` naming the operation |
| Error forms | S3 XML `<Error><Code/><Message/><Resource/><RequestId/></Error>` with codes `NoSuchBucket NoSuchKey BucketAlreadyOwnedByYou BucketAlreadyExists BucketNotEmpty InvalidArgument InvalidBucketName MalformedXML EntityTooLarge EntityTooSmall InvalidPart InvalidPartOrder NoSuchUpload PreconditionFailed NotModified(304) InvalidRange(416) SignatureDoesNotMatch InvalidAccessKeyId AccessDenied RequestTimeTooSkewed NotImplemented RequestTimeout(504) QuorumUnsatisfiable(503, extension) InvalidRequest(type mismatch)` |
| Name escaping (FR-019) | bucket names must match `^[a-z0-9][a-z0-9.-]{1,61}[a-z0-9]$`; containers violating this are exposed as `x--<hex(name)>` and listed with the true name in `?spacestorage=containers`; keys are binary-safe UTF-8 (percent-encoded in XML with `encoding-type=url`) |
| Stock clients (SC-001) | `aws s3`/`aws s3api` (path-style + static credentials), `aws-sdk-s3` (Rust), `boto3`, `mc`, `s3cmd`, `rclone`, `restic` |
| Metrics | protocol label `s3`; `kind` = operation name (`put_object`, `get_object`, `list_objects_v2`, …) |

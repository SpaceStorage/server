# Protocol Contract: `elasticsearch`

**Crate**: `crates/handler-elasticsearch` | **Stack**: `axum`/`hyper` 1.x (shared with `admin-http`), `serde_json` | Research: R5

| Item | Value |
|------|-------|
| Wire version | HTTP/1.1 (keep-alive) and HTTP/2 over TLS (ALPN); REST API compatible with **Elasticsearch 7.x/8.x clients**: `GET /` returns `version.number` from `protocols.elasticsearch.version` (default `8.15.0`), `tagline`, `cluster_name`; every response carries `X-Elastic-Product: Elasticsearch`; `Accept`/`Content-Type` `application/json` and `application/vnd.elasticsearch+json;compatible-with=8` |
| Signature (FR-004) | valid HTTP/1.x request line within 1 s (or TLS ClientHello when the entrypoint is encrypted); otherwise `400 Bad Request` text/plain and close |
| Authentication | `Authorization: Basic` (user:secret) → `Authenticator::Password`; `ApiKey` scheme accepted as `base64(user:secret)` alias; missing/invalid → `401` with `security_exception` body and `WWW-Authenticate: Basic realm="SpaceStorage"` |
| Namespace / schema | credential-bound (FR-009a); index = container in schema `public` |
| Session identity | `User-Agent` → `client_app`; `X-Opaque-Id` echoed |
| Type option | `PUT /{index}` body `{"settings":{"index":{"spacestorage":{"type":"<type>","<opt>":<value>}}}}`; default `document_store`; `mappings` accepted (dynamic; explicit field types recorded as hints only) |
| Listing (FR-013) | `GET /_cat/indices[?v&h=index,spacestorage.type,docs.count]` (extra column `spacestorage.type`), `GET /_spacestorage/containers` (JSON), `GET /_alias`, `GET /{index}` (settings incl. `spacestorage.type`), `HEAD /{index}` |
| Native mappings | `document_store` ↔ index documents (`_id`, `_source`); `relational_table` ↔ documents whose `_source` is the row (PK tuple joined by `\|` as `_id`); `kv_collection` ↔ documents `{"value": …}` with key as `_id` |
| Canonical carrier | foreign-type containers return `_source` = canonical envelope object; `GET /{index}/_spacestorage/{key}` returns raw canonical bytes; `PUT /{index}/_doc/{id}` with a body that is a canonical envelope is accepted for any type |
| Type ops | `POST /{index}/_spacestorage/{op}` with canonical `op-args` body (e.g. `_spacestorage/knn`), result canonical `op-result`; also ES-idiomatic sugar `POST /{index}/_search` with `{"knn": {"field": "vector", "query_vector": […], "k": 10}}` lowered to `TypeOp{knn}` for `vector_collection` |
| Options | headers `X-SpaceStorage-Quorum`, `X-SpaceStorage-Timeout`, `X-SpaceStorage-Session`; params `spacestorage_quorum`, `spacestorage_timeout`; native `timeout=`, `wait_for_active_shards=`; response headers `X-SpaceStorage-Applied-Quorum/-Timeout`, `X-SpaceStorage-Options-Source`; `GET /_spacestorage/options` |
| Endpoints (v1) | `GET /`, `GET /_cluster/health[/{index}]`, `GET /_cluster/state` (minimal), `GET /_nodes` (this node), `GET /_cat/indices|health|nodes`, `PUT/GET/HEAD/DELETE /{index}`, `PUT/POST /{index}/_doc[/{id}]`, `PUT /{index}/_create/{id}`, `GET/HEAD /{index}/_doc/{id}`, `GET /{index}/_source/{id}`, `DELETE /{index}/_doc/{id}`, `POST /{index}/_update/{id}` (`doc`, `doc_as_upsert`, `upsert`), `POST /_bulk`, `POST /{index}/_bulk` (`index|create|update|delete`, NDJSON, `?refresh` ignored), `GET/POST /{index}/_search` (`query`: `match_all match term terms range bool exists ids prefix wildcard match_phrase multi_match(simple)`; `from size sort _source track_total_hits`; `aggs`: `terms min max sum avg value_count stats cardinality(approx=exact)`), `POST /_msearch`, `POST /{index}/_count`, `POST /{index}/_delete_by_query`, `POST /{index}/_update_by_query` (script-less `doc` only), `GET /{index}/_mapping` (derived), `PUT /{index}/_mapping` (hints), `GET/PUT /{index}/_settings`, `POST /{index}/_refresh|_flush` (no-op 200), `GET /_mget`, `GET /_search/scroll` + `?scroll=` (server-side cursor, 10 000 max), `GET /_spacestorage/*` |
| Not supported (v1) | analyzers/full-text scoring beyond simple token match (documented as term/prefix semantics), `_reindex`, ILM/templates, `_sql`, `_eql`, security APIs, painless scripts, nested/parent-child, percolator → `501 not_implemented_exception` naming the endpoint or query clause |
| Error forms | ES error envelope `{"error":{"root_cause":[…],"type":"…","reason":"…"},"status":N}` — types: `index_not_found_exception` (404), `resource_already_exists_exception` (400), `mapper_parsing_exception` (400, type mismatch), `illegal_argument_exception` (400), `not_implemented_exception` (501), `timeout_exception` (504), `unavailable_shards_exception` (503, quorum), `security_exception` (401/403) |
| Name escaping (FR-019) | index names must be lowercase without `\ / * ? " < > | , #` and not start with `- _ +`; containers violating this are exposed as `--<hex(name)>` and listed with the true name in `_spacestorage/containers` |
| Stock clients (SC-001) | `curl`, `elasticsearch` (Rust), `elasticsearch-py` 8.x, `@elastic/elasticsearch`, Java REST client, Logstash/Beats output (bulk) |
| Metrics | protocol label `elasticsearch`; `kind` from endpoint (`index`, `get`, `search`, `bulk`, …) |
